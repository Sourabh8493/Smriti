## What makes a good image here

**Transparent background PNG is required**, not optional. The silhouette is
produced by rendering the same file with a `brightness(0)` filter — a white or
photographic background turns the whole square black and the question becomes
impossible. Cut the object out cleanly before saving.

Beyond that:

- **Distinctive outline.** The shadow is all the patient gets. A xorai and a
  covered bowl photographed from the same angle make an unfair question.
- **Side-on or three-quarter view**, whichever reads more clearly in outline.
  A rhino head-on is unrecognisable as a shadow.
- **No overlapping props**, no hands holding the object.
- **Square crop, ~800×800px**, object filling most of the frame.

Level 1 objects should be things anyone would name instantly. Level 3 is where
the culturally specific objects belong — that difficulty comes from
familiarity, which is exactly what the task is probing.
